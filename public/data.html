Baris yang tidak dapat diimpor

Ekspor ke Excel

Mengunduh seluruh data aktif sebagai file .xlsx.

Sesuai template menghasilkan file dengan 5 sheet seperti Template_Matriks_Penugasan_dan_Honor_Petugas.xlsx: Dashboard, Data Penugasan, Referensi, Rekap Honor Bulanan, dan Rekap Jenis Kegiatan. Formula rekap tetap hidup, tahun analisis dan nama petugas terisi otomatis.

Cetakan: template bawaan aplikasi.

Batas baris dan kolom mengikuti file template yang dipakai. Bila data melebihi batas, gunakan ekspor data saja.

Template untuk diisi di Excel

Unduh template kosong yang kapasitasnya sudah diperbesar, isi nama petugas pada kolom A sheet Rekap Honor Bulanan dan Rekap Jenis Kegiatan, lalu impor kembali ke sini.
